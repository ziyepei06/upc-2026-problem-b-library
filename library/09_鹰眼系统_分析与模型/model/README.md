# 计算与推理模型（reference implementation）

把 Hawk-Eye 那条流水线拆成可运行的几段。**只有 numpy**，Python 3.9+，无需安装任何东西。

```bash
cd 2026/research/hawkeye/model
python3 demo_2026b.py      # 端到端：2026 B 题数据 → 落点 + 不确定度
python3 triangulate.py     # 多相机三角测量 + 协方差
python3 kalman.py          # 时序滤波（重力作为已知输入）
```

| 文件 | 对应 Hawk-Eye 的哪一段 | 内容 |
|---|---|---|
| `triangulate.py` | 前段：标定 + 多视角重建 | 针孔模型、`look_at` 生成外参、DLT 三角测量、重投影误差、位置协方差 |
| `kalman.py` | 中段：延迟滤波 | 常速度卡尔曼滤波，重力作为控制输入，过程噪声来自未建模加速度（阻力/Magnus） |
| `physics.py` | 后段：飞行模型 | 阻力 + Magnus 的 ODE、Carré 的 C_d(Re) 表、Goff & Carré 的 C_l(S_p)、自旋衰减、RK4 积分 |
| `estimator.py` | 后段：反演 + 预测 | 两帧/三帧估计器、到球门平面的落点求解、蒙特卡洛、进球判定 |
| `demo_2026b.py` | 全部串起来 | 2026 B 题的数值结果 |

## 模型链

```
相机标定 (K, R, t)                                  ← 每台相机一次
   ↓ 2D 检测 + 跨视角关联
三角测量 (DLT, SVD)  →  cov = σ² (JᵀJ)⁻¹
   ↓ 25–500 Hz 的观测序列
时序滤波 (KF / EKF)  →  状态 [p, v]，协方差 P
   ↓ 一步预测
飞行模型 (RK4: 重力 + 阻力 + Magnus)  →  p(t), v(t)
   ↓ 求根 t*（x = 门平面）
落点 + 协方差传播  →  (y*, z*) ± 2σ 椭圆
   ↓
判定：|y*| < 3.66 且 0 < z* < 2.44 ?
```

## 两帧问题的特殊之处

Hawk-Eye 靠「多相机 + 高帧率」把每个环节的噪声压到毫米级；2026 B 题只剩两个采样点，于是：

- 三角测量那一段被题目跳过了（它直接给 3D 坐标），但**它的噪声水平依然决定最终结论**；
- 滤波那一段退化成两点差分（KF 在只有 2 个观测时与差分等价）；
- 飞行模型从「辅助平滑」变成「唯一的信息来源」——阻力与自旋不建模，落点就系统性偏掉；
- 协方差必须手工传播（解析公式或蒙特卡洛），否则无法回答「我们的预测有多准」。

这正是笔记 06 里那张误差放大表的来源：`σ_v = √2 σ/h ≈ 28.3σ`，`σ_a = √6 σ/h² ≈ 980σ`。

## 不确定度

蒙特卡洛（两帧估计器，2000 次抽样，噪声加在 p(0.05) 与 p(0.10) 上）：

| σ（每次定位） | σ_y | σ_z | P(进球) |
|---|---|---|---|
| 1 mm | 0.9 cm | 0.9 cm | 1.000 |
| 2 mm | 1.8 cm | 1.7 cm | 1.000 |
| 5 mm | 4.6 cm | 4.3 cm | 1.000 |
| 10 mm | 9.1 cm | 8.6 cm | 1.000 |
| 20 mm | 18.3 cm | 17.2 cm | 0.998 |

对照：Hawk-Eye 网球位置误差 3.6 mm、足球门线验收 ±1.5 cm。也就是说题面坐标若精确到 1–5 mm，结论与工业验收同量级；到 2 cm 时不确定度开始与「距立柱 0.54 m」同一数量级，必须报告。

## 用这个模型写论文时怎么说

1. **方法**：给出上面的模型链，并把「用两帧估初速 + 用飞行模型外推」写成算法 1（伪代码 10 行）。
2. **验证**：用合成数据（正演 → 两帧 → 反演）报 RMSD；用真实数据验证水平面；垂直方向明确写 limitation。
3. **不确定度**：解析公式 + 蒙特卡洛两路互证；给分场景表格（噪声档 × 自旋档）。
4. **敏感性**：列出各参数对 y*、z* 的偏导/影响量级，指出主导项（观测噪声 > 自旋 > 阻力 > 自旋衰减）。
5. **适用边界**：噪声 > 2 cm、或自旋 > 4500 rpm（Cant et al. 2019 指出该转速以上估计不可靠）时方法失效。

## 与真实系统的差异

Hawk-Eye 不公开的部分：滤波器的调参（过程噪声）、多视角融合的权重、球检测的失效恢复策略。公开的部分：相机数量与帧率、三角测量原理、门线判定时机、以及「用物理模型外推预测」（LBW 的球路预测、GLT 的最后几帧外推）。我们的实现覆盖了公开部分的数学骨架，调参部分按「物理可解释」取值（σ_acc = 1 m/s² 对应阻力量级）。
