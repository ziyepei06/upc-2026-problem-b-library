# 07 计算推理模型

系统从「一堆像素」到「球是否进门」要过四道计算：**三角测量 → 时序滤波 → 飞行模型外推 → 不确定度传播**。这一篇把每一道的公式、代码位置和数值结果写清楚，可以直接当论文的方法节骨架。

配套实现：`../model/`（纯 numpy，可直接跑）。

## 1. 观测模型：相机与三角测量

相机是针孔模型，3×4 投影矩阵 `P = K [R | t]`，世界点 `X` 投影到像素 `x ~ P X`。给定球在 N 个视角中的像素坐标 `(u_i, v_i)`，3D 位置由齐次方程 `A X = 0` 的最小二乘解给出（DLT，SVD）：

```
[u_i P_3 - P_1] X = 0
[v_i P_3 - P_2] X = 0
```

位置协方差：`C = σ_px² (JᵀJ)⁻¹`，J 为重投影对 X 的雅可比。

**实测量级**（`model/triangulate.py` 的 demo）：两台相机、基线 12 m、f = 2000 px、1 像素噪声 → 重建误差 **7.7 mm**，各轴 1σ ≈ 8/22/15 mm。可见在「几个像素」的检测精度下，三角测量的位置误差落在毫米到厘米级——这正是 Hawk-Eye 宣称的量级，也是题面数据可信度的参照。

对 2026 B 题：这一段被题目跳过了（直接给 3D 坐标），但它告诉我们**坐标的精度上限取决于检测精度与基线**，所以后面所有误差分析都从「σ = 1–20 mm」这个区间展开。

## 2. 时序滤波：把观测变成状态

真实系统每帧都有观测，用卡尔曼滤波平滑并外推。状态 `x = [p, v]`，重力是已知输入：

```
x_k = F x_{k-1} + B g,     F = [[I, dt I], [0, I]],  B = [[dt²/2 I], [dt I]]
P_k = F P Fᵀ + Q           Q = 由未建模加速度（阻力、Magnus）决定的过程噪声
K   = P Hᵀ (H P Hᵀ + R)⁻¹,  H = [I, 0]
```

实现见 `model/kalman.py`。三帧数据上的结果（σ_pos = 5 mm，过程噪声 σ_acc = 1 m/s²）：

```
v = (29.64, 8.64, 5.78) m/s  ± 0.077 m/s
```

与两点差分 `(29.2, 8.2, 6.0)` 的差别正好体现了滤波的作用：**它把测到的 z 下沉分一部分给重力，而不是全部当作速度**。

关键认识：当只有两个观测时，KF 与直接差分等价；真正让滤波有价值的是第三个及以后的观测，以及**它顺带给出的协方差矩阵**。题面只有两帧，所以我们必须手算协方差（见第 4 节）。

## 3. 飞行模型：为什么不能用抛物线

球在 0.3 s 内飞 11 m 时，空气动力不可忽略：

```
dv/dt = -g ẑ  -  (½ ρ A C_d |v| v)/m  +  (½ ρ A C_l |v|²)/m · (ω̂ × v̂)
C_d = C_d(Re),  Re = |v| D / ν
C_l = 0.505 S_p,  S_p = R ω / |v|
```

- C_d(Re) 用 Carré 风洞数据表（drag crisis 在 Re ≈ 7×10⁴–1.3×10⁵）；
- C_l 用 Goff & Carré 的线性关系（S_p ≲ 0.3 内有效）；
- 自旋按 5–15%/18 m 的实测衰减率做指数衰减（τ ≈ 6 s）。

对题面数据：|v| = 30.9 m/s → Re = 4.5×10⁵ → **C_d = 0.189**。阻力让到达时间从 0.3253 s 变成 0.3440 s，落点 z 从 1.873 m 降到 **1.836 m**（低 3.7 cm）。侧旋（绕 z 轴，ω̂ × v̂ 指向 +y）的效果：

| ω [rpm] | 落点 y [m] | Δy（相对无旋） |
|---|---|---|
| 0 | 3.118 | 0 |
| 150 | 3.198 | +0.080 |
| 300 | 3.278 | +0.160 |
| 450 | 3.360 | +0.242 |
| 600 | 3.442 | +0.324 |

也就是说：**600 rpm 的侧旋能把球从「距立柱 0.54 m」推到「距立柱 0.22 m」**——在临界样本上，自旋是能改变判定结论的量级，而题面没有给自旋，只能作为先验参数处理（这就是笔记 06 说「自旋不可辨识」的定量依据）。

## 4. 不确定度传播：解析 + 蒙特卡洛

两帧差分求速度，误差被 1/h 放大；三帧二阶差分求加速度，被 1/h² 放大：

```
σ_v = √2 σ / h  = 28.3 σ
σ_a = √6 σ / h² = 980 σ          (h = 0.05 s)
```

落点 y 的一阶传播：`σ_y ≈ σ_pos ⊕ T·σ_v ≈ √(1 + 2T²/h²)·σ`，T = 0.325 s 时 ≈ 9.2σ。代入数值：

| σ [mm] | σ_v [mm/s] | σ_y [cm]（解析） | σ_y [cm]（MC） | P(进球) |
|---|---|---|---|---|
| 1 | 28 | 0.92 | 0.9 | 1.000 |
| 2 | 57 | 1.84 | 1.8 | 1.000 |
| 5 | 141 | 4.60 | 4.6 | 1.000 |
| 10 | 283 | 9.20 | 9.1 | 1.000 |
| 20 | 566 | 18.40 | 18.3 | 0.998 |

解析与蒙特卡洛吻合到 1% 以内，说明线性化在这个场景可用（因为噪声远小于门的尺度）。**写论文时两路互证是加分项**：解析给洞察（误差 ∝ σ/h），MC 给置信区间与失败概率。

## 5. 落点求解与判定

到门平面（x = 11 m）的到达时间：重力模型下 x 方向匀速 → `T = (11 − x₀)/v_x`；含阻力时用 RK4 积分 + 二分求根。判定：

```
进球 ⇔ |y*| < 3.66 且 0 < z* < 2.44
```

更严格的写法是「预测分布与球门区域的交叠概率」：

```
P(进球) = P(|y*| < 3.66, 0 < z* < 2.44)
```

临界样本上这个概率对 σ 极敏感（见上表最后一行），所以论文里应当给出「P(进球) = 0.998 ± …」而不是「球进/不进」的二元结论。

## 6. 三类误差：统计、模型、结构

| 类型 | 来源 | 怎么处理 |
|---|---|---|
| 统计误差 | 坐标噪声 σ | 解析 + MC，给 1σ/2σ 区间 |
| 模型误差 | 阻力、Magnus、自旋衰减的系数不确定性 | 参数区间扫描，报落点的包络 |
| 结构误差 | 模型形式本身错（如真实存在未被建模的风） | 明写 limitation，给出「模型失效的判据」 |

题面数据下，两帧估计 `(3.118, 1.873)` 与三帧常加速度估计 `(2.617, 2.013)` 相差 **Δy = −0.50 m**——这是模型误差，比 5 mm 噪声下的统计误差（4.6 cm）大一个数量级。**论文必须在两者之间给出判据**（例如：若认为 t=0 的初始条件是精确约束，则用三帧；若认为它只是标称值，则用两帧并把差别当作系统不确定度）。

## 7. 与 Hawk-Eye 实际系统的对应

| 环节 | Hawk-Eye 公开做法 | 我们的实现 | 差异 |
|---|---|---|---|
| 相机 | 每门 7 台 500 fps；网球 10 台 25 Hz | 2 台演示 | 我们不需要重建，只借用协方差量级 |
| 三角测量 | 标定 + 多视角 DLT | `triangulate.py` 同法 | 一致 |
| 滤波 | 「delay filter」平滑 + 遮挡恢复 | `kalman.py` 常速度 KF | 我们无遮挡问题；他们要多视角失效恢复 |
| 外推 | 物理模型 + 最后几帧（LBW、GLT） | `physics.py` + 求根 | 一致 |
| 不确定度 | 验收标准（±1.5 cm、RMSD 分档） | 解析 + MC | 我们按 FIFA 的「分场景最坏值」组织报告 |
| 未公开 | 调参、融合权重、失效阈值 | — | 论文里不必假装知道 |
